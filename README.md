# RANEPA Student — веб-приложение для iPhone

Помощник студента РАНХиГС, который ставится на экран «Домой» прямо из Safari — без App Store, аккаунта и сервера. Расписание, задания и дедлайны, посещаемость, оценки, сессия, оплата обучения и календарь. Работает без интернета, данные хранятся только на телефоне.

> Неофициальное приложение. Не связано с РАНХиГС и не получает данные из систем университета — открытого API у них нет. Расписание вводите вы сами, загружаете из файла (.ics/.csv) или получаете файлом от старосты.

## Что внутри архива

| Папка | Что это |
| --- | --- |
| `dist/` | **Готовое приложение.** Эту папку нужно разместить в интернете (см. ниже). |
| `src/`, `tests/`, `build.mjs` | Исходный код и тесты — нужны, только если захотите что-то поменять. |

## Как установить на iPhone

Safari добавляет на экран «Домой» только сайты, открытые по адресу `https://…`. Поэтому сначала папку `dist` нужно один раз разместить в интернете — это бесплатно и занимает несколько минут. Сервер ничего не хранит: на хостинге лежат только файлы приложения, а ваши данные остаются на телефоне.

### Шаг 1. Разместить папку `dist` (с компьютера)

**Вариант А — Netlify Drop (проще всего).**
1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку `dist` в окно браузера.
3. Через несколько секунд появится адрес вида `https://название.netlify.app`.
4. Зарегистрируйтесь бесплатно и нажмите «Claim» / «Сохранить сайт» — иначе неподтверждённый сайт со временем удаляется.

**Вариант Б — GitHub Pages.**
1. Создайте публичный репозиторий на [github.com](https://github.com/new).
2. Загрузите в него **содержимое** папки `dist` (файл `index.html` должен оказаться в корне): «Add file» → «Upload files».
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту адрес появится на той же странице: `https://ваш-логин.github.io/название/`.

**Вариант В — любой хостинг статических файлов с HTTPS** (Cloudflare Pages, Яндекс Object Storage, свой сервер). Достаточно загрузить содержимое `dist`.

### Шаг 2. Добавить на экран «Домой» (на iPhone)

1. Откройте полученный адрес **в Safari** (не во встроенном браузере Telegram или ВКонтакте).
2. Нажмите «Поделиться» — в iOS 26 она в меню «•••» справа от адресной строки, в iOS 18 и раньше — на нижней панели.
3. Выберите «На экран „Домой“», оставьте включённым «Открыть как веб-приложение» и нажмите «Добавить».
4. Откройте приложение с новой иконки. Первый запуск — с интернетом, дальше оно работает и офлайн.

Ссылку можно отправить одногруппникам — каждый установит приложение себе, данные у всех свои.

## Важно знать

- **Данные живут на телефоне.** Они не синхронизируются между устройствами. Данные во вкладке Safari и в установленном приложении хранятся отдельно, поэтому заполняйте расписание уже в установленном приложении.
- **Резервная копия.** «Ещё» → «Календарь iPhone и резервная копия» → «Сохранить копию» (в «Файлы» или iCloud Drive). Если удалить иконку приложения, его данные удалятся вместе с ней.
- **Напоминания.** Веб-приложение без сервера не может само присылать уведомления, когда закрыто. Поэтому напоминания ставит Календарь iPhone: «Ещё» → «Календарь iPhone и резервная копия» → «Добавить в Календарь». Пары, дедлайны (по умолчанию за сутки и за час), экзамены и сроки оплаты добавятся с напоминаниями. При повторном добавлении события могут задвоиться.
- **Расписание группы.** Староста заполняет расписание у себя и отправляет файл кнопкой «Отправить расписание»; остальные загружают его через «Импорт расписания». Повторный импорт обновляет занятия без дублей.
- **Оплата.** Приложение не принимает платежи и не хранит данные карт. Внесённые суммы — ваш учёт, они помечены как неподтверждённые; для оплаты есть ссылка на официальную страницу.
- **Средний балл и посещаемость** считаются по вашим записям и показанным формулам — это не официальные показатели.

## Возможности

- **Главная:** приветствие, дата и номер учебной недели, ближайшая пара с обратным отсчётом, пары на сегодня, дедлайны и счётчики, ближайший экзамен, напоминание об оплате, посещаемость, быстрые действия.
- **Расписание:** день и неделя, перелистывание дней свайпом, прошлые и будущие недели, текущая пара, отмены и переносы, фильтры, повторяющиеся занятия на весь семестр («только это» / «это и следующие»), время по часовому поясу института.
  - Пара длится 1 ч 20 мин: конец считается сам от времени начала. Кнопка «Сделать пару длиннее» позволяет задать своё окончание, «Обычная длительность» возвращает расчёт. Стандартную длительность можно поменять в профиле.
  - В одно время может быть только одна пара: приложение не даст сохранить, перенести или вернуть пару на занятое время (пары встык — можно), при импорте такие пары пропускает, а старые пересечения помечает.
  - Преподаватель подставляется сам: у каждой дисциплины 1–2 преподавателя (например, лектор и семинарист); на лекцию ставится первый, на семинар и практику — второй. Список преподавателей — во вкладке «Преподаватели» раздела «Дисциплины».
- **Задания:** статусы и вычисляемое «Просрочено», группировка по срокам, фильтры, поиск, календарь дедлайнов, приоритеты, ссылки на материалы.
- **Календарь:** месяц, неделя, день; пары, дедлайны, сессия, оплата и личные события разными цветами.
- **Моя успеваемость:** 100-балльная система — по каждой дисциплине до 100 баллов; вы вносите полученные баллы, и они прибавляются к уже набранным (сумма не может превысить 100, ошибочную запись можно удалить).
- **Ещё:** посещаемость (статистика, по дисциплинам, по неделям, история), сессия, оплата, дисциплины и преподаватели, поиск, импорт `.ics`/`.csv` (UTF-8 и Windows-1251), экспорт в Календарь, резервная копия, демо-данные, светлая и тёмная тема, выход из профиля (удаляет данные с устройства, перед этим предлагает сохранить копию), значок с числом срочных заданий на иконке (iOS 16.4+).

## Обновление

Соберите новую версию (или получите новый `dist`) и замените файлы на хостинге. Установленное приложение само скачает обновление и покажет «Доступна новая версия — нажмите, чтобы обновить». Данные при этом сохраняются.

## Для разработчиков

```bash
npm install
npm run typecheck
npm test          # 88 тестов: время и часовые пояса, статусы, статистика, импорт, экспорт в календарь, хранилище, пересечения пар, баллы, преподаватели
npm run build     # dist/ — приложение, preview/ — одностраничная версия для просмотра
npx serve dist    # локальный просмотр (service worker работает на localhost)
```

Стек: React 19, TypeScript (strict), esbuild, без серверной части. Бизнес-логика (`src/shared/domain`, `src/shared/integrations`) общая с мобильной версией на React Native + Supabase — при переходе на неё данные можно перенести, структура записей совпадает.

Цвета: спокойный синий `#3B5BBF` (в духе фирменного синего РАНХиГС) и мягкий розово-бордовый `#C2416A` для срочного; логотип и символика университета не используются. Все цвета — в начале `src/styles.css`.
